Alcance del módulo+

El módulo estructura reportes de terceros, los cruza con contratos, facturación y registros contables, destaca diferencias y prepara un archivo con el formato de carga del sistema. El formato de entrada, las excepciones y la vía de conexión se definen para cada operación.

¿Qué entrega para la carga contable de arriendos?+

Prepara un archivo con el formato de carga del sistema y deja visibles las diferencias entre reportes, contratos, facturación y reajustes para revisión del equipo.
